🌦️ Weatherly – Weather Forecast Android App

Weatherly is a modern Android weather application developed using Kotlin and Jetpack Compose. It allows users to search for any city and access real-time weather information along with upcoming weather forecasts through API integration.

The application provides a clean, intuitive, and user-friendly interface with a Deep Ocean Blue theme.

✨ Features

- 🌍 City Search: Search for weather information by entering a city name.
- 🌡️ Real-Time Weather: Get current weather conditions for the searched city.
- 💧 Humidity Information: View current humidity levels.
- 💨 Wind Speed: Check the current wind speed.
- 📅 Weather Forecast: View upcoming weather forecasts.
- 📍 Geocoding Integration: Convert city names into geographical coordinates.
- 🎨 Modern UI: Clean interface built with Jetpack Compose and Material 3.
- 🔄 API Integration: Fetch live weather data using Retrofit.

🏗️ Application Architecture

Weatherly follows a structured Android development approach:

- UI Layer: Jetpack Compose for building the application interface.
- ViewModel: Manages UI state and weather-related operations.
- API Layer: Retrofit handles communication with weather and geocoding APIs.
- Data Layer: Handles API responses and JSON data parsing.

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the Repository

git clone 

2. Open the Project

- Open Android Studio.
- Select Open Project.
- Choose the cloned Weatherly project.
- Wait for Gradle synchronization.

3. Configure OpenWeather API Key

1. Create an account on "OpenWeather" (https://openweathermap.org/).
2. Generate your API key.
3. Open the weather API configuration in the project.
4. Replace the placeholder API key with your own key.

Important: Never upload your personal API key to a public GitHub repository.

4. Run the Application

- Connect an Android device or start an emulator.
- Click the Run button in Android Studio.
- Search for a city to explore its weather information.

🎯 Project Objective

The main objective of Weatherly is to develop a simple and user-friendly weather forecasting application that provides real-time weather information through API integration.

This project demonstrates practical implementation of Android development concepts, including Jetpack Compose, REST API integration, JSON parsing, ViewModel, and asynchronous programming.
